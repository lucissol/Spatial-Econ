Spatial Macro-Micro: Top-Down Inequality Modeling This repository implements a Top-Down Macro-to-Micro framework to analyze spatial inequality dynamics. It replicates the core logic of large-scale spatial econometric models (such as NiREMS) by linking a 2-region Spatial Vector Autoregression (SpVAR) to a Heterogeneous Agent (Aiyagari) micro-foundation.

The primary goal is to simulate how macroeconomic shocks in "Core" vs. "Periphery" regions transmit into household-level wealth inequality, capturing the asymmetric impact of recessions on financially constrained agents.
